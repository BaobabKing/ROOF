# ROOF
ROOF: Robustness-Oriented Optimal Factorization for Fluorescence Crosstalk Correction

This repository provides a MATLAB implementation of ROOF, a semi-blind crosstalk correction method for multi-band fluorescence microscopy. The ROOF algorithm is based on non-negative matrix factorization (NMF) with a reference calibration regularization, enabling robust, accurate, and efficient spectral unmixing.

---

The package contains four main subfolders:

- Algorithms/ – ROOF implementation, along with comparison methods, visualization tools, and performance evaluation utilities  
- Examples/ – Example scripts for running the algorithms  
- TestImages/ – Includes one simulated dataset and one real fluorescence image  
- ExperimentResults/ – Sample outputs and benchmarking results
